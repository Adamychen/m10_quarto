Genera 20 filas sintéticas usando la API de Llamus. Pide el JSON en el prompt (como en 02a-prompt-engineering.qmd) y extrae la respuesta con el helper parse_json_response(). Usa como columnas: age, hours_per_week, education, income. Incluye 2 ejemplos few-shot en el prompt. Usa temperatura 0.8.

import json, re
from openai import OpenAI

def parse_json_response(content: str) -> dict:
    """Extrae JSON de una respuesta que puede venir envuelta en ```json ... ```."""
    match = re.search(r"```(?:json)?\s*(\{.*?\})\s*```", content, re.DOTALL)
    if match:
        content = match.group(1)
    return json.loads(content)
