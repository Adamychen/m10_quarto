Demo — La atención: ¿en qué se fija cada palabra?

Pulsa una palabra y mira en cuáles del resto de la frase se apoya para interpretarse. Después comprueba qué pasa cuando solo puede mirar hacia atrás, como en un LLM generativo.

Demo que acompaña a Arquitectura Transformer. Se ejecuta en el navegador con Shinylive y no necesita clave de API.

NoteEsto es una ilustración, no un modelo real

Los pesos de esta demo están diseñados a mano para que se vea la idea de la atención con claridad. Un modelo real tiene muchas cabezas de atención y ninguna se comporta de forma tan limpia ni tan fácil de leer.

Una misma palabra puede significar cosas muy distintas según las que la rodean: no es lo mismo el banco donde te sientas que el banco que quiebra. La atención es el mecanismo con el que un Transformer le permite a cada palabra consultar al resto de la frase para decidir cómo interpretarse.

Pulsa cualquier palabra y verás en cuáles se apoya: cuanto más grueso el arco, más atención le presta. Si es tu primera vez, pulsa Empezar ▶ y sigue el recorrido guiado de seis pasos.

def attention(s, sel, causal):
    """Pesos normalizados {palabra: porcentaje} de la palabra seleccionada."""
    n = len(s["words"])
    raw = dict(s["att"].get(sel) or {})
    if not raw:
        for j in range(n):
            if j != sel:
                raw[j] = {1: 3.0, 2: 1.5}.get(abs(j - sel), 0.5)
    if causal:
        raw = {j: w for j, w in raw.items() if j < sel}
    total = sum(raw.values())
    return {j: w / total for j, w in raw.items()} if total else {}


def layout(words):
    xs, x = [], 10
    for w in words:
        width = 11 * len(w) + 24
        xs.append((x, width))
        x += width + 8
    return xs, x + 2


current = reactive.value(None)
pending = reactive.value(None)  # palabra que debe seleccionarse tras un cambio de frase del recorrido
step = reactive.value(-1)


def go(k):
    sent, word, causal, _ = TOUR[k]
    step.set(k)
    if int(input.sent()) != sent:
        pending.set(word)
        ui.update_radio_buttons("sent", selected=str(sent))
    else:
        current.set(word)
    ui.update_switch("causal", value=causal)


@reactive.effect
def _reset():
    s = SENTENCES[int(input.sent())]
    with reactive.isolate():
        p = pending()
    current.set(p if p is not None else s["default"])
    pending.set(None)


@reactive.effect
@reactive.event(input.w)
def _click():
    current.set(int(input.w()))


@reactive.effect
@reactive.event(input.next)
def _next():
    go(min(step() + 1, len(TOUR) - 1))


@reactive.effect
@reactive.event(input.prev)
def _prev():
    go(max(step() - 1, 0))

@render.ui
def figure():
    s = SENTENCES[int(input.sent())]
    words, causal = s["words"], input.causal()
    sel = current()
    if sel is None or sel >= len(words):
        return ui.HTML("")
    att = attention(s, sel, causal)
    xs, total_w = layout(words)
    base_y, h = 120, 44

    def cx(i):
        return xs[i][0] + xs[i][1] / 2

    parts, labels, placed, cands = [], [], [], []
    for j, w in sorted(att.items(), key=lambda kv: kv[1]):
        dist = abs(cx(j) - cx(sel))
        top = base_y - min(125, 25 + dist * 0.22) - 40
        mx = (cx(sel) + cx(j)) / 2
        parts.append(
            f"<path d='M{cx(sel)},{base_y} Q{mx},{top} {cx(j)},{base_y}' "
            f"fill='none' stroke='{DARK}' stroke-width='{1 + 11 * w:.1f}' "
            f"stroke-opacity='{0.25 + 0.75 * w:.2f}' stroke-linecap='round'/>"
        )
        cands.append((w, mx, (base_y + top) / 2))
    for w, mx, apex in sorted(cands, reverse=True):
        if w >= 0.12 and all(abs(mx - px) > 40 or abs(apex - py) > 14 for px, py in placed):
            placed.append((mx, apex))
            labels.append(
                f"<text x='{mx}' y='{apex - 4}' text-anchor='middle' font-size='12' font-weight='600' "
                f"fill='{DARK}' stroke='#fff' stroke-width='4' paint-order='stroke'>{w:.0%}</text>"
            )
    for i, word in enumerate(words):
        x, wd = xs[i]
        future = causal and i > sel
        if i == sel:
            fill, fop, tcol, deco = DARK, 1, "#fff", "none"
        elif i in att:
            fill, fop, tcol, deco = YELLOW, 0.3 + 0.7 * att[i], "#000", "none"
        else:
            fill, fop, tcol, deco = "none", 1, "currentColor", "line-through" if future else "none"
        opacity = 0.4 if future else 1
        parts.append(
            f"<g class='word' style='cursor:pointer' opacity='{opacity}' "
            f"onclick=\"Shiny.setInputValue('w', {i}, {{priority: 'event'}})\">"
            f"<rect x='{x}' y='{base_y}' width='{wd}' height='{h}' rx='8' fill='{fill}' "
            f"fill-opacity='{fop}' stroke='{DARK if i == sel else GRAY}' stroke-width='1.5'/>"
            f"<text x='{x + wd / 2}' y='{base_y + 28}' text-anchor='middle' font-size='17' "
            f"fill='{tcol}' text-decoration='{deco}'>{word}</text></g>"
        )
    svg = (
        f"<svg viewBox='0 0 {total_w} {base_y + h + 8}' width='100%' "
        f"style='max-width:{max(total_w, 480)}px;display:block;margin:8px 0' "
        f"font-family='system-ui,sans-serif'>{''.join(parts)}{''.join(labels)}</svg>"
    )

    word = words[sel]
    if att:
        ranked = sorted(att.items(), key=lambda kv: -kv[1])
        bars = "".join(
            f"<span>{words[j]}</span><span class='track'><span class='fill' style='display:block;"
            f"width:{100 * w / ranked[0][1]:.0f}%'></span></span><span>{w:.0%}</span>"
            for j, w in ranked[:3]
        )
        summary = f"<p style='margin:0 0 4px'>Al interpretar <b>«{word}»</b>, presta más atención a:</p><div class='bars'>{bars}</div>"
    else:
        summary = (
            f"<p><b>«{word}»</b> es la primera palabra: un LLM generativo todavía no tiene "
            f"ninguna palabra anterior en la que apoyarse.</p>"
        )

    why = s["why"].get(sel)
    lost = [words[j] for j in sorted(s["att"].get(sel, {})) if j > sel]
    note = ""
    if causal and lost and why:
        note = (
            f"<p style='border-left:4px solid {ORANGE};padding-left:10px;margin-top:10px'>"
            f"Un LLM generativo no puede ver lo que viene después: se pierde "
            f"<b>{', '.join('«' + w + '»' for w in lost)}</b>, justo las pistas que aclaraban el sentido. "
            f"Con lo que sí ve, la interpretación queda mucho menos clara.</p>"
        )
    elif why:
        note = f"<p style='border-left:4px solid {ORANGE};padding-left:10px;margin-top:10px'>{why}</p>"
    mode = (
        "<b>Modo LLM generativo:</b> las palabras tachadas aún no existen."
        if causal
        else "<b>Modo codificador (tipo BERT):</b> cada palabra mira antes y después."
    )
    return ui.HTML(
        f"<div class='card'><div class='muted'>{mode} Pulsa otra palabra para cambiar.</div>"
        f"{svg}{summary}{note}</div>"
    )

@render.ui
def matrix():
    if not input.nums():
        return ui.HTML("")
    s = SENTENCES[int(input.sent())]
    words, causal, sel = s["words"], input.causal(), current()
    head = "".join(f"<th class='col'>{w}</th>" for w in words)
    rows = []
    for i, w in enumerate(words):
        att = attention(s, i, causal)
        cells = []
        for j in range(len(words)):
            if causal and j > i:
                cells.append(
                    "<td style='background:repeating-linear-gradient(45deg,#f3f4f6,#f3f4f6 4px,#e5e7eb 4px,#e5e7eb 8px)'></td>"
                )
                continue
            v = att.get(j, 0.0)
            txt = f"{v * 100:.0f}" if v >= 0.005 else ""
            col = "#fff" if v > 0.35 else "#111"
            cells.append(f"<td style='background:rgba(48,105,152,{min(1, v * 1.6):.2f});color:{col}'>{txt}</td>")
        style = f"outline:2px solid {ORANGE};outline-offset:-1px" if i == sel else ""
        rows.append(
            f"<tr style='{style}' onclick=\"Shiny.setInputValue('w', {i}, {{priority: 'event'}})\">"
            f"<th style='text-align:right'>{w}</th>{''.join(cells)}</tr>"
        )
    note = (
        "Cada fila es una palabra y reparte su atención (100 %) entre las columnas. "
        + ("La zona rayada es lo que un LLM generativo no puede ver: el triángulo de la <b>máscara causal</b>. " if causal else "")
        + "Los pesos son ilustrativos. Pulsa una fila para seleccionar esa palabra."
    )
    return ui.HTML(
        f"<div class='card' style='overflow-x:auto'><table class='mat'><thead><tr><th></th>{head}</tr></thead>"
        f"<tbody>{''.join(rows)}</tbody></table><p class='muted' style='margin:6px 0 0'>{note}</p></div>"
    )

Qué observar

  1. Con la primera frase, pulsa «banco»: se apoya sobre todo en «parque» y «senté». Pasa a la segunda frase y vuelve a pulsar «banco»: ahora son «cerró» y «quiebra». Es la misma palabra, pero se interpreta de forma distinta porque el contexto es distinto.
  2. En las dos frases del trofeo, pulsa «era». Es un pronombre: no significa nada por sí mismo y necesita buscar a quién se refiere. Con «grande» mira al trofeo; con «pequeña», a la maleta. Cambia una palabra y cambia a quién mira.
  3. Activa el interruptor «Ver como un LLM generativo» y vuelve a pulsar «banco» en la frase del parque. «parque» queda tachada: un LLM que genera texto palabra a palabra todavía no la ha visto, así que no puede usarla para interpretar «banco».
  4. Con el interruptor activo, pulsa «era» en la frase del trofeo. Aquí no cambia casi nada, porque las pistas ya están antes.
  5. Marca «Ver los números» con el interruptor activo: la tabla completa muestra un triángulo rayado. Es la máscara causal: cada palabra (fila) solo puede atender a las columnas anteriores.

Qué has visto

  • La atención permite que cada palabra se interprete según las demás, no de forma aislada.
  • Los modelos tipo BERT (codificadores) miran a ambos lados. Los LLM generativos (ChatGPT, Qwen, Llama…) son decodificadores y solo miran hacia atrás, porque generan palabra a palabra. Por eso funcionan bien con pronombres, cuyas pistas suelen estar antes, pero no pueden usar lo que todavía no han escrito.
  • Esto es una simplificación: en un modelo real hay muchas cabezas de atención a la vez, y cada una se fija en cosas distintas.
WarningUna precaución sobre el interruptor

Aquí el modo «LLM generativo» simplemente tapa las palabras posteriores para que se vea la restricción. Un decodificador real no funciona tapando a posteriori: se entrena con esa restricción desde el principio y aprende a trabajar con ella.

¿Y en un modelo real? Continúa con la segunda parte: pesos reales de un BERT, con seis cabezas de atención que se fijan en cosas distintas.

Para ver cómo se define esta restricción en el modelo (máscara causal) y qué cambia entre las variantes de la arquitectura, consulta Del Transformer original al decoder-only moderno.

def attention(s, sel, causal):
    """Pesos normalizados {palabra: porcentaje} de la palabra seleccionada."""
    n = len(s["words"])
    raw = dict(s["att"].get(sel) or {})
    if not raw:
        for j in range(n):
            if j != sel:
                raw[j] = {1: 3.0, 2: 1.5}.get(abs(j - sel), 0.5)
    if causal:
        raw = {j: w for j, w in raw.items() if j < sel}
    total = sum(raw.values())
    return {j: w / total for j, w in raw.items()} if total else {}


def layout(words):
    xs, x = [], 10
    for w in words:
        width = 11 * len(w) + 24
        xs.append((x, width))
        x += width + 8
    return xs, x + 2

## Qué observar

1. Con la primera frase, **pulsa «banco»**: se apoya sobre todo en «parque» y «senté». Pasa a la segunda frase y vuelve a pulsar «banco»: ahora son «cerró» y «quiebra». Es la misma palabra, pero se interpreta de forma distinta porque el contexto es distinto.
2. En las dos frases del trofeo, **pulsa «era»**. Es un pronombre: no significa nada por sí mismo y necesita buscar a quién se refiere. Con «grande» mira al trofeo; con «pequeña», a la maleta. Cambia una palabra y cambia a quién mira.
3. **Activa el interruptor «Ver como un LLM generativo»** y vuelve a pulsar «banco» en la frase del parque. «parque» queda tachada: un LLM que genera texto palabra a palabra todavía no la ha visto, así que no puede usarla para interpretar «banco».
4. Con el interruptor activo, pulsa «era» en la frase del trofeo. Aquí no cambia casi nada, porque las pistas ya están antes.
5. Marca **«Ver los números»** con el interruptor activo: la tabla completa muestra un triángulo rayado. Es la **máscara causal**: cada palabra (fila) solo puede atender a las columnas anteriores.

## Qué has visto

- La atención permite que **cada palabra se interprete según las demás**, no de forma aislada.
- Los modelos tipo BERT (codificadores) miran a ambos lados. Los **LLM generativos** (ChatGPT, Qwen, Llama…) son decodificadores y solo miran hacia atrás, porque generan palabra a palabra. Por eso funcionan bien con pronombres, cuyas pistas suelen estar antes, pero no pueden usar lo que todavía no han escrito.
- Esto es una simplificación: en un modelo real hay muchas cabezas de atención a la vez, y cada una se fija en cosas distintas.

::: {.callout-warning}
## Una precaución sobre el interruptor

Aquí el modo «LLM generativo» simplemente tapa las palabras posteriores para que se vea la restricción. Un decodificador real no funciona tapando a posteriori: se entrena con esa restricción desde el principio y aprende a trabajar con ella.
:::

**¿Y en un modelo real?** Continúa con la [segunda parte](atencion-modelo-real.qmd): pesos reales de un BERT, con seis cabezas de atención que se fijan en cosas distintas.

Para ver cómo se define esta restricción en el modelo (máscara causal) y qué cambia entre las variantes de la arquitectura, consulta [Del Transformer original al decoder-only moderno](../bloque1/01a-transformer.qmd#sec-original-vs-moderno).
