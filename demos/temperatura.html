Demo — Temperatura: ¿cuánta creatividad le pides al modelo?

Genera la siguiente palabra varias veces y mira cómo la temperatura convierte un modelo repetitivo en uno creativo, y después en uno caótico.

Demo que acompaña a LLM e inferencia. Las probabilidades se midieron una vez con Qwen3-0.6B y se guardaron como datos estáticos, así que la demo se ejecuta en el navegador sin API ni clave.

Un LLM no «decide» la siguiente palabra: calcula una probabilidad para cada candidata y saca una al azar. La temperatura controla cuánto se respetan esas probabilidades. Con temperatura baja casi siempre gana la favorita; con temperatura alta el abanico se aplana y las palabras raras tienen opción.

Elige una frase, mueve la temperatura (o usa los botones Determinista, Equilibrada, Creativa y Caótica) y pulsa Generar 10. Cada palabra que sale suma en su barra (×n), y la raya negra de cada barra marca la probabilidad original del modelo: así ves cuánto la ha deformado la temperatura.

samples = reactive.value([])
last_batch = reactive.value(0)


def distribution(i, temp, cut):
    """Probabilidades tras aplicar temperatura y recorte, y máscara de las que sobreviven."""
    p = np.array(PROMPTS[i]["probs"], dtype=float)
    if temp <= 0:
        q = np.zeros_like(p)
        q[np.argmax(p)] = 1.0
    else:
        logits = np.log(np.maximum(p, 1e-12)) / temp
        q = np.exp(logits - logits.max())
        q /= q.sum()
    order = np.argsort(-q)
    keep = np.ones(len(q), dtype=bool)
    if cut == "k3":
        keep[order[3:]] = False
    elif cut == "p90":
        cum = np.cumsum(q[order])
        n = int(np.searchsorted(cum, 0.9) + 1)
        keep[order[n:]] = False
    q = np.where(keep, q, 0.0)
    return q / q.sum(), keep


def mood(temp):
    if temp <= 0:
        return "Determinista: siempre gana la favorita."
    if temp < 0.6:
        return "Conservadora: la favorita casi siempre gana."
    if temp <= 1.05:
        return "Cerca de 1: el abanico tal como lo calcula el modelo."
    if temp < 1.6:
        return "Creativa: las candidatas menos probables ganan peso."
    return "Muy plana: lo raro sale a menudo."

@reactive.effect

    samples.set([])
    last_batch.set(0)


def _draw(n):
    q, _ = distribution(int(input.prompt()), input.temp(), input.cut())
    draws = np.random.default_rng().choice(len(q), size=n, p=q)
    samples.set((samples() + [int(d) for d in draws])[-200:])
    last_batch.set(n)


@reactive.effect
@reactive.event(input.gen1)
def _gen1():
    _draw(1)


@reactive.effect
@reactive.event(input.gen10)
def _gen10():
    _draw(10)


@render.ui
def fan():
    i = int(input.prompt())
    words = PROMPTS[i]["words"]
    base = np.array(PROMPTS[i]["probs"], dtype=float)
    q, keep = distribution(i, input.temp(), input.cut())
    s = samples()
    counts = np.bincount(s, minlength=len(words)) if s else np.zeros(len(words), dtype=int)
    scale = max(q.max(), base.max())
    cells = []
    for j, w in enumerate(words):
        rare = base[j] < RARE
        color = ORANGE if rare else BLUE
        orig = f"<span class='orig' style='left:{100 * base[j] / scale:.1f}%'></span>"
        if keep[j]:
            fill = f"<span class='fill' style='width:{100 * q[j] / scale:.1f}%;background:{color}'></span>"
            label = f"{q[j]:.0%}" if q[j] >= 0.005 else "&lt;1 %"
            wstyle = f"color:{ORANGE}" if rare else ""
        else:
            fill, label = "", "fuera"
            wstyle = "text-decoration:line-through;opacity:.45"
        badge = (
            f"<span class='count' style='background:{color};color:#fff'>×{counts[j]}</span>"
            if counts[j] else "<span></span>"
        )
        cells.append(
            f"<span class='w' style='{wstyle}'>{w}</span>"
            f"<span class='track' style='opacity:{1 if keep[j] else .4}'>{fill}{orig}</span>"
            f"<span class='muted' style='font-size:.8em'>{label}</span>{badge}"
        )
    legend = (
        f"<p class='muted' style='margin-top:6px'>"
        f"<span style='color:{BLUE}'>■</span> plausible · "
        f"<span style='color:{ORANGE}'>■</span> poco plausible (el modelo le daba &lt;2 %) · "
        f"<b>│</b> probabilidad original (T = 1) · <b>×n</b> veces que ha salido</p>"
    )
    return ui.HTML(
        f"<div class='card'><b>Abanico de la siguiente palabra</b>"
        f"<div class='fan' style='margin-top:8px'>{''.join(cells)}</div>{legend}</div>"
    )


@render.ui
def results():
    i = int(input.prompt())
    s = samples()
    if not s:
        return ui.HTML(
            "<div class='card muted'>Pulsa «Generar 10» para ver qué escribe el modelo. "
            "Las veces que sale cada palabra se acumulan en el abanico.</div>"
        )
    words = PROMPTS[i]["words"]
    base = PROMPTS[i]["probs"]
    n_new = last_batch()
    shown = s[-MAX_SHOWN:][::-1]
    chips = "".join(
        f"<span class='gen{' new' if k < n_new else ''}' style='animation-delay:{0.04 * k:.2f}s'>"
        f"{PROMPTS[i]['prompt']} <b style='color:{ORANGE if base[d] < RARE else DARK}'>{words[d]}</b></span>"
        for k, d in enumerate(shown)
    )
    distinct = len(set(s))
    rare = sum(base[d] < RARE for d in s)
    stats = (
        f"<div class='stats'>"
        f"<div class='stat'><span class='muted'>Generadas</span><b>{len(s)}</b></div>"
        f"<div class='stat'><span class='muted'>Palabras distintas</span><b>{distinct}</b></div>"
        f"<div class='stat'><span class='muted'>Poco plausibles</span>"
        f"<b style='color:{ORANGE if rare else GREEN}'>{rare} <span style='font-size:.6em'>"
        f"({rare / len(s):.0%})</span></b></div></div>"
    )
    more = f"<p class='muted'>Se muestran las {MAX_SHOWN} últimas.</p>" if len(s) > MAX_SHOWN else ""
    return ui.HTML(f"<div class='card'><b>Lo que ha escrito el modelo</b>{stats}<div>{chips}</div>{more}</div>")

    )

Qué observar

  1. Con la frase del gato y temperatura 0, pulsa «Generar 10» varias veces: sale siempre la misma palabra. Es el modo determinista, el que se usa cuando quieres respuestas reproducibles.
  2. Sube a 1,0. Ahora aparecen varias palabras, pero casi todas razonables. Es el abanico tal como lo calcula el modelo.
  3. Sube a 2,0. El abanico se aplana: las barras naranjas (palabras que el modelo consideraba absurdas) empiezan a salir. Ese es el momento en que el texto deja de tener sentido.
  4. Cambia a la frase del café. El modelo está casi seguro de que sigue «leche», así que la temperatura apenas cambia nada hasta valores altos. La temperatura solo da libertad donde el modelo duda.
  5. Vuelve a 1,5 y elige «Solo las 3 más probables». Las palabras raras desaparecen aunque la temperatura sea alta: recortar el abanico es la forma de tener variedad sin los disparates.

Qué has visto

  • El modelo no decide: saca una palabra de un abanico de probabilidades. La temperatura reparte esa probabilidad de forma más igualitaria (alta) o más concentrada (baja).
  • A temperatura 0 siempre sale lo mismo. A temperaturas altas aparece lo absurdo. Para tareas factuales o estructuradas conviene temperatura baja; para escritura creativa, media.
  • Top-k y top-p recortan el abanico antes de sortear, y por eso se combinan con la temperatura en producción.
WarningQué es real y qué está simplificado
  • Las probabilidades son reales, de Qwen3-0.6B, un modelo pequeño: sus preferencias (por ejemplo, que un gato se suba «al coche» antes que «al sofá») son menos sensatas que las de un LLM grande.
  • Las candidatas son doce palabras elegidas a mano, incluidas algunas absurdas para que se vea la cola. Un modelo real reparte probabilidad entre decenas de miles de tokens, y su siguiente token puede ser un fragmento de palabra.
  • Las probabilidades se renormalizaron entre esas doce candidatas, no son las absolutas del modelo.
  • Una palabra de varios tokens se puntúa multiplicando las probabilidades de sus tokens.

Para ver cómo se fijan estos parámetros al llamar a un modelo, vuelve a LLM e inferencia.

def _draw(n):
    q, _ = distribution(int(input.prompt()), input.temp(), input.cut())
    draws = np.random.default_rng().choice(len(q), size=n, p=q)
    samples.set((samples() + [int(d) for d in draws])[-200:])
    last_batch.set(n)

@render.ui
def fan():
    i = int(input.prompt())
    words = PROMPTS[i]["words"]
    base = np.array(PROMPTS[i]["probs"], dtype=float)
    q, keep = distribution(i, input.temp(), input.cut())
    s = samples()
    counts = np.bincount(s, minlength=len(words)) if s else np.zeros(len(words), dtype=int)
    scale = max(q.max(), base.max())
    cells = []
    for j, w in enumerate(words):
        rare = base[j] < RARE
        color = ORANGE if rare else BLUE
        orig = f"<span class='orig' style='left:{100 * base[j] / scale:.1f}%'></span>"
        if keep[j]:
            fill = f"<span class='fill' style='width:{100 * q[j] / scale:.1f}%;background:{color}'></span>"
            label = f"{q[j]:.0%}" if q[j] >= 0.005 else "&lt;1 %"
            wstyle = f"color:{ORANGE}" if rare else ""
        else:
            fill, label = "", "fuera"
            wstyle = "text-decoration:line-through;opacity:.45"
        badge = (
            f"<span class='count' style='background:{color};color:#fff'>×{counts[j]}</span>"
            if counts[j] else "<span></span>"
        )
        cells.append(
            f"<span class='w' style='{wstyle}'>{w}</span>"
            f"<span class='track' style='opacity:{1 if keep[j] else .4}'>{fill}{orig}</span>"
            f"<span class='muted' style='font-size:.8em'>{label}</span>{badge}"
        )
    legend = (
        f"<p class='muted' style='margin-top:6px'>"
        f"<span style='color:{BLUE}'>■</span> plausible · "
        f"<span style='color:{ORANGE}'>■</span> poco plausible (el modelo le daba &lt;2 %) · "
        f"<b>│</b> probabilidad original (T = 1) · <b>×n</b> veces que ha salido</p>"
    )
    return ui.HTML(
        f"<div class='card'><b>Abanico de la siguiente palabra</b>"
        f"<div class='fan' style='margin-top:8px'>{''.join(cells)}</div>{legend}</div>"
    )

## Qué observar

1. Con la frase del **gato** y temperatura **0**, pulsa «Generar 10» varias veces: sale siempre la misma palabra. Es el modo determinista, el que se usa cuando quieres respuestas reproducibles.
2. Sube a **1,0**. Ahora aparecen varias palabras, pero casi todas razonables. Es el abanico tal como lo calcula el modelo.
3. Sube a **2,0**. El abanico se aplana: las barras naranjas (palabras que el modelo consideraba absurdas) empiezan a salir. Ese es el momento en que el texto deja de tener sentido.
4. Cambia a la frase del **café**. El modelo está casi seguro de que sigue «leche», así que la temperatura apenas cambia nada hasta valores altos. La temperatura solo da libertad donde el modelo duda.
5. Vuelve a 1,5 y elige **«Solo las 3 más probables»**. Las palabras raras desaparecen aunque la temperatura sea alta: recortar el abanico es la forma de tener variedad sin los disparates.

## Qué has visto

- El modelo no decide: **saca una palabra de un abanico de probabilidades**. La temperatura reparte esa probabilidad de forma más igualitaria (alta) o más concentrada (baja).
- A temperatura 0 siempre sale lo mismo. A temperaturas altas aparece lo absurdo. Para tareas factuales o estructuradas conviene temperatura baja; para escritura creativa, media.
- **Top-k** y **top-p** recortan el abanico antes de sortear, y por eso se combinan con la temperatura en producción.

::: {.callout-warning}
## Qué es real y qué está simplificado

- Las probabilidades son reales, de `Qwen3-0.6B`, un modelo pequeño: sus preferencias (por ejemplo, que un gato se suba «al coche» antes que «al sofá») son menos sensatas que las de un LLM grande.
- Las candidatas son **doce palabras elegidas a mano**, incluidas algunas absurdas para que se vea la cola. Un modelo real reparte probabilidad entre decenas de miles de tokens, y su siguiente token puede ser un fragmento de palabra.
- Las probabilidades se **renormalizaron entre esas doce candidatas**, no son las absolutas del modelo.
- Una palabra de varios tokens se puntúa multiplicando las probabilidades de sus tokens.
:::

Para ver cómo se fijan estos parámetros al llamar a un modelo, vuelve a [LLM e inferencia](../bloque1/01b-llms.qmd#sec-parametros-inferencia).
