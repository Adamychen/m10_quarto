Bibliografía y recursos de referencia

Esta página agrupa los recursos externos que complementan los materiales del módulo: documentación de herramientas, lecturas de contexto y un índice curado de Model/System Cards. La bibliografía completa de los papers y fuentes citadas en el sitio se genera automáticamente al final de esta página desde el archivo references.bib.

Documentación técnica

  • Hugging Face Hub — repositorio de modelos open-weight y open-source.
  • LangChain Expression Language (LCEL) — guía oficial de orquestación con LCEL.
  • LlamaIndex — documentación de LlamaIndex para indexación documental.
  • Model Context Protocol Specification — especificación abierta de Anthropic para MCP.
  • RAGAS — framework de evaluación de RAG.
  • Hugging Face TRL — librería de SFT/RLHF/DPO.
  • DeepEval — framework de evaluación como unit testing.
  • LangSmith — trazabilidad y evaluación online (LangChain).
  • Langfuse — plataforma open source de observabilidad LLM.
  • Microsoft Presidio — detección y anonimización de PII.
  • vLLM — servidor de inferencia LLM de alto rendimiento.
  • Ollama — runtime local para modelos open-weight.
  • DAIR.AI Prompt Engineering Guide — guía canónica de prompting.
