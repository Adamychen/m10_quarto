Bloque 3 — Aplicaciones: RAG Avanzado, Datos Sintéticos y Fine-tuning

Carga: HT: 6h | HPD: 4h

Competencias asociadas: CE-4, CE-5

Objetivos del bloque

Implementar sistemas RAG de calidad producción con evaluación objetiva, generar datos sintéticos validados estadísticamente, y aplicar técnicas de ajuste fino eficientes (LoRA/QLoRA) para adaptar modelos a dominios específicos.

Mapa conceptual del bloque

Los tres pilares de este bloque son complementarios y se refuerzan mutuamente:

  • RAG Avanzado te enseña a construir sistemas de pregunta-respuesta robustos, con evaluación objetiva (RAGAS) y técnicas avanzadas (re-ranking, query expansion, multi-fuente).
  • Datos Sintéticos te permite generar datos de entrenamiento, testing o anonimización cuando los datos reales son insuficientes o sensibles.
  • Fine-tuning te permite adaptar modelos open-source a tu dominio específico cuando RAG y prompting no bastan.

Contenido del bloque

Tema Archivo Duración estimada
RAG Avanzado — Re-ranking, HyDE, RAG-Fusion, RAGAS, multi-fuente 03b-rag-avanzado.qmd 3h
Datos Sintéticos — CTGAN, TVAE, TabDDPM, SDV, validación estadística 03a-datos-sinteticos.qmd 1.5h
Fine-tuning eficiente — LoRA, QLoRA, PEFT, cuándo adaptar modelos 03c-fine-tuning.qmd 1.5h
HPD 4 — Sistema RAG sobre datos mixtos hpd4-rag-mixto.qmd 4h

Ruta de aprendizaje recomendada

  1. Empieza con RAG Avanzado: es el tema central del bloque y la base del HPD 4. Aprenderás a mejorar la calidad de tus sistemas RAG con re-ranking, query expansion y evaluación objetiva con RAGAS.
  2. Continúa con Datos Sintéticos: aprenderás a generar datos verosímiles con LLMs (enfoque intuitivo) y con modelos especializados (CTGAN, TVAE).
  3. Cierra con Fine-tuning: entenderás cuándo y cómo adaptar modelos open-source a tu dominio con LoRA/QLoRA.
  4. Ponlo todo en práctica con el HPD 4: construirás un sistema RAG completo sobre datos mixtos (PDFs + SQL) con evaluación RAGAS.

Lecturas obligatorias

  • Es, S. et al. (2023). RAGAS: Automated Evaluation of Retrieval Augmented Generation. arXiv:2309.15217
  • Hu, E. et al. (2022). LoRA: Low-Rank Adaptation of Large Language Models. ICLR. arXiv:2106.09685 — secciones 1-4
  • Lewis, P. et al. (2020). Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks. NeurIPS. arXiv:2005.11401

Resumen del bloque

Este bloque te da las herramientas para llevar tus sistemas IA a calidad de producción:

  • Bloque 4: evaluarás y desplegarás estos sistemas con gobernanza, detectando alucinaciones, sesgos y documentando con Model Cards.
  • Proyecto integrador: combinarás RAG + datos sintéticos + fine-tuning en un sistema completo de tu dominio.

Ahora pasa al primer tema: RAG Avanzado.
